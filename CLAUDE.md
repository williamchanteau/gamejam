## Joueur
Vif, saut variable, coyote 0,1 s, buffer 0,1 s, double saut via flag (off). Dash = esquive : i-frames tout le dash (~0,22 s), ~84 px, cd ~0,55 s, direction tenue sinon face, 1 dash aérien rechargé au sol, images rémanentes. Combo 3 coups aux dagues (visuel seul : frames atkI_F dans art/player.ts, hitbox = config.combo), +1 mana par coup touché. Mort : genou à terre puis dissolution en cendres (deathRetryDelay). Cinématiques : Player.walkTo, ui/Iris.ts (portail). Mana pleine → "Éclat lunaire" (croissant perforant, 20 dégâts). Amélioration du banquet : double vague, ou dash qui plante les dagues (24 dégâts). 4 PV (choix utilisateur), 8 en VRAIMENT FACILE où tous les dégâts infligés aux boss sont ×2 (Boss.damage, après les tests de dégâts bruts de McKing), invu 1,2 s, recul, hit-stop 70 ms.

## Boss (data-driven)
Boss générique unique. Boss.minHp = plancher de PV tant qu'un passage scripté est dû ou en cours (épreuve de Nycthor, festin de McKing jusqu'à la fin du repas ou l'étranglement), pour qu'un gros coup ne le saute ni ne l'écourte. Pattern = télégraphe → actif → récupération (boss ouvert, yeux éteints). Télégraphe ≥ 0,6 s (P1) / ≥ 0,45 s (P2), couleur danger. Sélection pondérée, jamais 3× le même, pause ≥ 0,4 s. À 50 % PV : 1 s invu + rugissement + tremblement, nouveaux patterns, vitesse ×1,15. Barre de vie nommée EN BAS (phase 2 : la moitié restante remplit la barre). Arène 2 écrans. Annonceur (ui/Announcer.ts, ~2,3 s, jeu figé via ArenaScene.frozen, rejoué après une mort, sauté via pause > recommencer).
- Boss 1 « Ysolde, la Dame d'Argent » (200 PV ; code : bosses/ysolde.ts, textures `ysol_*` ; guerrière en armure de chevalier : acier et filigrane d'or, heaume couronné à visière, cape et tabard violets, longs cheveux blancs articulés qui traînent selon la vitesse (driveHair), longue épée ; splash art `ysol_splash` pour l'annonceur via BossDef.portrait) : fente + revers montant (swings), épée tournoyante ×2 → bond écrasant + ondes de pics (slam, elevated), rafale de lames spectrales qui traquent (flurry, P1 ×2), charge à l'épaule (far). P2 : épée rouge sombre (`ysol_sword_r`), téléportation derrière le joueur + repère (warp), combo 3 coups, rafale ×3, double écrasement.
- Boss 2 « Nycthor, le Porteur de Lanternes » (260 PV ; ÉTAGE 1, la Crypte des Lanternes ; code : bosses/nycthor.ts, art/nycthor.ts, art/nycthorRig.ts, bosses/lanterns.ts, scenes/DarkBossScene.ts ; créature sombre aux membres trop longs, tête-cage, lanternes pendues au corps, salle plongée dans l'obscurité) : rush, ombre, lancer. P2 : moulinet ; épreuve obligatoire à la moitié de la phase 2 (65 PV) : 3 lanternes à frapper dans n'importe quel ordre, jouée une seule fois, un échec lance la fauche à −3 cœurs puis le combat reprend.
- Boss 3 « McKing, le Roi des Burgers » (280 PV ; ÉTAGE 2, la Salle à manger ; code : bosses/mcking.ts, art/mcking.ts, scenes/BurgerScene.ts ; décor : art/dining.ts + rooms.ts buildDining, sans plateformes) : le héros mange au bout de la longue table, le roi est attablé à l'autre bout (grande chaise, plat de burgers, hors champ jusqu'au travelling). Assis : depth 4.9 (derrière table et sol), repasse à 7 pendant le bond d'entrée. Charge dans le mur = étourdi : étoiles en orbite + yeux en spirale (dizzy). Plat ventre, rot et burger géant : onde de choc blanche, pas de rouge (airArc, shock, waves ; le rot part de la bouche, MOUTH), la salle tremble à chaque lancer (quake). Rugissement de phase 2 : tambour des poings sur le bide (drumBeat, DRUM).
